## How to pick up

If you're returning to this session and want to continue:

1. Check the audit result at
   `~/Desktop/GhostLM/docs/contamination_audit.md` (Mac) or via
   `git pull` once it lands. If it confirms the partial-run signal
   (negligible verbatim leakage), the v1.0 GPU spend is unblocked
   from the contamination angle.

2. Run the threat-intel collectors at least once to grow the corpus:

       ssh ghostlm-mac 'cd ~/Desktop/GhostLM && PYTHONPATH=. python3 scripts/collect_vendor_research.py'
       ssh ghostlm-mac 'cd ~/Desktop/GhostLM && PYTHONPATH=. python3 scripts/collect_cisa_advisories.py'
       ssh ghostlm-mac 'cd ~/Desktop/GhostLM && PYTHONPATH=. python3 scripts/collect_misp_feeds.py'

   Each takes 5-30 min depending on `--max-per-feed`. Output goes to
   `data/raw/{vendor_research,cisa_advisories,misp_feeds}.jsonl`.

3. Once the RAG index uploads, **rebench v0.9 with retrieval**:

       cd ~/Desktop/GhostLM && PYTHONPATH=. python3 scripts/rag_chat.py \\
           --checkpoint checkpoints/phase19_chat_v09/best_model.pt

   If RAG-augmented v0.9 clears 30%+ on fact-recall v2 or 40%+ on
   debiased CTIBench, that's a real finding worth shipping as v0.9.3.

4. Smoke-test the distillation pipeline on Ollama before any paid
   provider runs:

       cd ~/Desktop/GhostLM && PYTHONPATH=. python3 scripts/distill_ctf_walkthroughs.py \\
           --provider ollama --model qwen2.5:14b --max-records 100

5. The big-ticket items still gated on outside dependencies:

   - **Rented GPU access** for the ~26h ghost-base pretrain.
   - **GGUF export** for llama.cpp / Ollama (~1 week of careful mapping
     work; documented in `scripts/quantize_v09.py`).
   - **fact-recall v2 expansion to n=200** (more handwriting).

## Why the session went this direction

The user said "what else, don't give me nothing" three times during
the session. The instinct each time was to keep shipping concrete
artifacts rather than wait for compute. That produced the 14
commits, three threat-intel collectors, one published HF Dataset,
and the four-script distillation pipeline. The downside is breadth
over depth in a few places: the audit is still running, the RAG
index hasn't uploaded, and the fact-recall v2 bench is at n=100 not
n=200. None of those are blockers for the v1.0 GPU run; they're all
follow-ups when bandwidth and time cooperate.

The shape of "what to do next" past this session is now genuinely
GPU-gated. Without rented compute, the project can keep growing
the corpus and the eval surface area, but the model itself can't
move past ghost-small until ghost-base trains.
